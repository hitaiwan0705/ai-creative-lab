# 測試計畫

本專案為純靜態網站，無自動化測試框架（無後端、無資料庫可供單元測試），
採用人工功能測試＋瀏覽器實機操作驗證，對照需求文件第十五節 A–F 分類。
可勾選版本請見 [../tests/manual-checklist.md](../tests/manual-checklist.md)。

## 測試方式

1. 在 `ai-creative-lab/` 目錄下啟動本機伺服器：`python3 -m http.server 8000`
   （純 `file://` 雙擊開啟也應可用，伺服器僅為測試方便）。
2. 依序開啟 `index.html`、`teacher.html`、`student.html`、`print.html`。
3. 依下列 A–F 類別實際操作，而非只看程式碼。

## 測試環境限制說明

本次測試使用 Chromium 核心的自動化瀏覽器工具與本機 HTTP 伺服器進行驗證，
未能涵蓋：實體 macOS Safari、實體斷網環境、實體 CP1200 印表機、
校內實際網路頻寬、真正的教室投影設備。上表標示 🟡 之項目請於正式上課前，
在實際教室桌機／投影設備上再次確認。
