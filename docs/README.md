# AI 文創實驗室：創造另一個我，讓故事動起來

高中生大學體驗營用互動教學網站。純靜態、可離線、不需登入、不需資料庫，
第一版不串接任何 AI API，不儲存學生肖像或個人資料。

## 快速開始

**本機直接開啟（最簡單）**

用 Chrome／Edge／Safari 直接開啟 `index.html`（雙擊或拖入瀏覽器）即可使用，
不需安裝任何套件、不需建置流程。

**本機簡易伺服器（可選）**

若瀏覽器對 `file://` 開啟有任何限制，可在 `ai-creative-lab/` 目錄下執行：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

部署方式請見 [DEPLOYMENT.md](DEPLOYMENT.md)（GitHub Pages）。
教師自訂文案／輪盤資料請見 [CONTENT_GUIDE.md](CONTENT_GUIDE.md)。
測試方式請見 [TEST_PLAN.md](TEST_PLAN.md) 與 [../tests/manual-checklist.md](../tests/manual-checklist.md)。

## 三種模式

| 頁面 | 用途 |
| --- | --- |
| `index.html` | 模式選擇首頁 |
| `teacher.html` | 教師投影授課：導覽、肖像權判斷題、CREATE、輪盤示範、劇情／分鏡教學、備援模式 |
| `student.html` | 學生操作：規則同意、角色卡、CREATE 組合器、輪盤、故事、三幕劇、分鏡、動畫 Prompt、匯出 |
| `print.html` | 輸出小隊：CP1200 規格、檔名工具、檢查清單、角色分工 |

## 技術重點

- HTML5 + CSS3（手寫，無 Tailwind／CDN）＋ Vanilla JavaScript
- 資料以 `<script>` 掛載至 `window.AICL.DATA`，不使用 `fetch()` 讀取 JSON，
  避免 `file://` 環境下的 CORS 限制
- 不使用 Cookie、不使用追蹤分析工具、不使用 localStorage 儲存個資或作品內容
- 匯出功能使用 `Blob` + `URL.createObjectURL`，不經任何伺服器
- 輪盤為純前端實作，不呼叫外部輪盤網站

## 已知限制

- 備援模式（綠／黃／紅燈）狀態僅存在教師頁當頁記憶體，不會同步到學生頁或其他分頁／裝置。
- 學生輸入僅存在瀏覽器記憶體，重新整理或關閉分頁即消失（隱私設計），請提醒學生務必先匯出備份。
- 列印檢查清單使用 `sessionStorage` 暫存勾選狀態（僅布林值，非個資），分頁關閉後會清除。
- 上傳連結（Google Drive／表單）為教師手動輸入之欄位，本身不做雲端串接或驗證。
- 輪盤視覺轉盤為裝飾用途（固定六色扇形），與選項數量無關；實際抽選結果以文字與 `aria-live` 播報為準，仍為均勻亂數。
- 無自動化測試框架（單元測試／E2E），已提供人工測試清單供教師與工程師使用。
- 僅提供繁體中文介面。
