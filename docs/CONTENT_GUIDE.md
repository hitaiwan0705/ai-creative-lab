# 內容編輯指南（給教師／非工程背景使用者）

本網站的文字內容分成兩種：**畫面上可直接編輯**（不需改程式碼）與
**需要修改檔案內容**（需要文字編輯器，但不需要寫程式）。

## 畫面上可直接編輯（現場就能改）

- **教師頁輪盤**：`04 輪盤` 區塊 → 選好一個輪盤後，點開「編輯這個輪盤的選項」，
  每行輸入一個選項，按「套用修改」即可，當場生效（僅限當次瀏覽器分頁，重新整理會還原）。
- **輸出頁上傳連結**：`print.html` 的「作品上傳入口」欄位，可直接貼上本場次
  實際的 Google Drive／表單網址。

## 需要修改檔案內容（文字編輯器即可，不需寫程式）

以下檔案都是簡單的 JavaScript「資料」檔，格式為 `"文字"` 用逗號分隔，
修改時請保留引號與逗號，避免刪到 `{ }` 或 `[ ]` 符號。

### `data/wheel-options.js`：六組輪盤的預設內容

```js
{
  id: "ability",
  label: "能力輪盤",
  items: [
    "能聽懂動物說話",
    "看得見物品的記憶",
    // 在這裡新增或修改一行，記得每行結尾加逗號
  ]
}
```

### `data/examples.js`：範例角色卡、範例三幕劇、範例分鏡、肖像權判斷題

- `exampleCharacter`：教師頁「02 角色」展示的範例角色卡。
- `exampleThreeAct` / `exampleOneLineStory` / `exampleStoryboard`：教師頁「05 劇情」
  「06 分鏡」的範例內容。
- `rightsQuiz`：肖像權判斷題，每題包含 `question`（題目）、`options`（三個選項，
  `correct: true` 標記正確答案）、`explain`（點擊後顯示的解釋文字）。

### `data/prompt-templates.js`：CREATE 範例、角色／分鏡／動畫 Prompt 模板文字

修改 `createExample.incomplete` / `createExample.complete` 可更換教師頁
「03 CREATE」的對照範例。

## 修改後如何確認

1. 用文字編輯器存檔後，直接重新整理瀏覽器頁面即可看到變更。
2. 若不確定格式是否正確，可請工程人員協助確認，或參考檔案中既有的其他項目
   照樣造句。
3. 修改資料檔不會影響網站其他功能（表單、匯出、輪盤邏輯等）。
