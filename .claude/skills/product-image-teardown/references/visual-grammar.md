# 視覺語法

圖的任務是「讓人依序讀懂設計決策」，不是展示美感。所有規則都服務於這個目的。

## 版面骨架

- 畫布：SVG `viewBox="0 0 1200 1500"`（4:5 直式），HTML 頁面內自適應縮放。
- 上方 0–14%：標題區。中文主題名（例：「為什麼這把削皮刀讓人覺得親和？」），下方可選一行小英文。
- 中段 14–84%：拆解區。
  - 中央軸 x = 600，部件沿軸縱向排列，相鄰部件之間保留至少 30 單位的空隙。
  - 左右標籤軌道：左軌 x 40–380、右軌 x 820–1160。標籤左右交錯，不要全部擠在一側。
- 下方 84–100%：意象總結帶。列出目標意象語彙組，有數據時顯示 SD 量表點位，沒有就顯示「待量測」虛線框。
- 四周安全邊距 40 單位，任何文字、線都不能超出。

## 部件

- 4–6 個；每個部件寬度 160–440 單位。
- 有去背照片時用 `<image>` 嵌入相對路徑；沒有照片時用簡化幾何輪廓（填色＋1.5 單位描邊）。不要用 SVG 模仿寫實照片。
- 所有部件同一視角（正視或同一側視），不混用。

## 標籤結構

```text
① 握柄｜霧面矽膠               ← 第一行：編號、部件名｜設計元素（中文 16–22 單位字級）
   低反光表面，可能降低冰冷感     ← 第二行：設計元素 → 意象（最多 18 字，14–16 單位）
   [推論]                         ← 證據標籤：文字＋外框樣式
```

- 中文部件名最多 6 字、說明最多 18 字。寫不下就改寫，不縮小字級。
- 英文可選，放在第二行之後，字級為中文的 60–70%。
- 編號 ①–⑥ 同時出現在標籤與部件旁，讓讀者不靠連線也能對應。

## 引導線

- 每條線只連接一個標籤和一個部件，只用水平與垂直線段，最多轉折兩次。
- 線不得穿過其他部件或文字。模板會把垂直段放在該高度範圍內所有部件的外側，所以只要不改渲染程式，線就不會穿過部件。
- 線型隨證據等級改變（不能只靠顏色）：

| 等級 | 線型 | 標籤外框 |
|---|---|---|
| 觀察 | 實線 1.5 | 實線框 |
| 推論 | 虛線 6 4 | 虛線框 |
| 數據 | 實線 2.5 | 實心底色框（白字） |

## 色彩角色

預設使用專案 CIS（見 `.claude/CLAUDE.md`）。以 ai-image-lab 為例，已驗證的對比（對紙底 `#FAFAF7`）：

| 角色 | 色碼 | 對比 | 用途 |
|---|---|---|---|
| 紙底 | `#FAFAF7` | — | 背景 |
| 墨色 | `#30343A` | 11.97:1 | 標題、內文 |
| 次要文字／線 | `#5C6068` | 6.03:1 | 說明文字、觀察線 |
| 觀察強調 | `#2148B8` Cobalt | 7.48:1 | 觀察標籤 |
| 推論強調 | `#A84A28` Terracotta 文字色 | 5.46:1 | 推論標籤 |
| 部件填色 | 取產品本色 | 描邊需 ≥ 3:1 | 部件輪廓 |

- 線與圖形物件對背景至少 3:1（WCAG 2.1 1.4.11），文字至少 4.5:1（1.4.3）。
- 淺灰（例如 `#DCE3F4` 只有 1.23:1）只能當大面積底色，不能當線或唯一的資訊載體。

## 字體

只用系統字體堆疊，不載入網路字體：

```css
font-family: 'Noto Sans TC', 'PingFang TC', 'Microsoft JhengHei', system-ui, sans-serif;
```

## 無障礙

- `<svg role="img" aria-labelledby="t d">`，內含 `<title id="t">` 與 `<desc id="d">`，`desc` 要用一段話描述整張圖的結論。
- HTML 頁面在圖下方附「文字版」清單，螢幕閱讀器與列印都能讀到同樣資訊（模板已內建）。
