# 人工測試清單（可列印勾選）

活動前請在實際使用的教室桌機／投影設備上，將以下項目逐項勾選。
分類對應需求文件第十五節 A–F，詳細測試結果說明見 [../docs/TEST_PLAN.md](../docs/TEST_PLAN.md)。

## A. 功能測試

- [ ] 教師頁 01–07 導覽皆可正確跳轉
- [ ] 上一頁／下一頁按鈕與鍵盤 ← → 正常
- [ ] Home／End 鍵可跳到第一段／最後一段
- [ ] 輪盤可抽選、重抽、接受、複製
- [ ] CREATE 欄位可正確組合 Prompt（簡短版／進階版皆正確且不同）
- [ ] 一句話故事四欄位正確帶入
- [ ] 三幕劇可摘要成三句
- [ ] 三格分鏡各自產生 Prompt，且角色名稱有帶入
- [ ] 動畫 Prompt 含動作順序、幅度、限制條件
- [ ] 學生頁可下載 5 個檔案（角色設定/Prompt/故事分鏡/JSON/可列印HTML）
- [ ] 備援模式（綠／黃／紅）切換立即生效，不需重新整理
- [ ] CREATE「清除」只清除 CREATE 區塊，不影響其他區塊
- [ ] 所有複製按鈕點擊後皆有成功提示文字
- [ ] 匯出前若必填欄位空白，會擋下並提示
- [ ] 輸出頁檢查清單可勾選並顯示完成度

## B. 安全與隱私檢查

- [ ] 搜尋程式碼確認無 API Key／Token／Secret
- [ ] 無不必要的外部請求（僅本地檔案）
- [ ] 未使用 Cookie 或追蹤工具
- [ ] 表單資料未送往第三方伺服器
- [ ] localStorage 未儲存姓名或創作內容
- [ ] 使用者輸入未以不安全方式插入 DOM
- [ ] 下載檔名已清理特殊字元
- [ ] 外部連結使用 `target="_blank" rel="noopener noreferrer"`

## C. 無障礙檢查

- [ ] 所有輸入欄位皆有 label
- [ ] 所有按鈕可用鍵盤操作（Tab／Enter／Space）
- [ ] Tab 順序合理，無跳頁或迴圈
- [ ] 焦點狀態清楚可見
- [ ] 文字與背景顏色對比足夠
- [ ] 輪盤結果有 `aria-live` 播報（可用螢幕閱讀器確認）
- [ ] 錯誤訊息顯示在對應欄位旁
- [ ] SVG／圖示搭配文字說明，不僅靠圖形傳達
- [ ] 動畫遵守 `prefers-reduced-motion`，且有手動關閉開關
- [ ] 手機模式按鈕觸控範圍足夠（不擁擠、不誤觸）

## D. 響應式測試

- [ ] 1920×1080（教室投影）
- [ ] 1366×768（一般桌機）
- [ ] 1024×768
- [ ] 768×1024
- [ ] 390×844
- [ ] 375×667（手機）
- [ ] 以上尺寸皆無水平捲軸、導覽不遮住內容、表單可閱讀、輪盤不超出畫面

## E. 離線測試

- [ ] 關閉網路後重新整理，教師／學生／輸出三頁皆可正常開啟
- [ ] 輪盤與 Prompt 組合離線正常運作
- [ ] 本地圖示與樣式離線正常顯示
- [ ] 匯出功能離線正常運作
- [ ] 外部 AI 工具連結在離線時有清楚提示（「將離開本網站」）

## F. 效能測試

- [ ] 校內網路下首次載入低於 2 秒
- [ ] 靜態資源總量遠低於 5MB
- [ ] 無過大圖片
- [ ] 無非必要 JavaScript
- [ ] 無明顯畫面跳動（Layout Shift）
- [ ] 教師投影捲動順暢，必要時可關閉動畫效果
