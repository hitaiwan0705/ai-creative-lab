# AI 形象實驗室：試試不同版本的自己

高中生微課程（60 分鐘）互動教學網站｜中國文化大學資訊傳播學系

- `index.html` 課程介紹
- `slides.html` 投影上課（18 頁）
- `student.html` 學生手機任務頁（Prompt 產生器、一鍵複製）

## 投影操作
| 鍵 | 功能 |
|---|---|
| ← → ／ 空白鍵 | 翻頁（手機可左右滑） |
| N | 教師講稿 |
| T | 全場計時（超過該段建議時間會變色） |
| O | 總覽跳頁 |
| F | 全螢幕 |

網址加 `#12` 可直接跳到第 12 頁。
