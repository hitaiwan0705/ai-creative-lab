# 用 Firefly 生成示範人物（10 張）

目標：**同一個虛構人物**的 10 個版本。關鍵是一致性——先生成原圖，其餘 9 張都從原圖「局部重畫」，不要每張重新文生圖（會變成不同人）。

## 步驟 0｜原圖 `original.jpg`（Firefly Text to Image，直式 3:4，相片）

```
自然光下的正面半身照，一位約 20 歲的台灣大學生，黑色中長直髮，穿素色淺灰圓領 T 恤，表情自然微笑，淺灰素面背景，真實相片質感，無濾鏡、無美顏，皮膚保留自然紋理
```
挑一張五官清楚、臉不被頭髮遮住的。之後全部用這張。

## 步驟 1｜配色 4 張（Generative Fill：只框「衣服＋背景」，不要框到臉和頭髮）

| 檔名 | 填入提示 |
|---|---|
| color-cool-low.jpg | 霧藍灰色針織上衣，冷色低彩度，淺藍灰背景 |
| color-cool-high.jpg | 鮮豔寶藍色上衣，冷色高彩度，青藍色背景 |
| color-warm-low.jpg | 奶茶色燕麥色上衣，暖色低彩度，米色背景 |
| color-warm-high.jpg | 亮橘紅色上衣，暖色高彩度，暖黃色背景 |

## 步驟 2｜髮型 3 張（Generative Fill：只框「頭髮範圍」，略大於原髮型）

| 檔名 | 填入提示 |
|---|---|
| hair-short.jpg | 俐落的短髮，自然黑色 |
| hair-curly.jpg | 蓬鬆自然捲髮，深棕色 |
| hair-bangs.jpg | 齊瀏海的中長髮，自然黑色 |

> 若生成結果「連臉都變了」——**保留下來**，那正是第 12 頁「AI 有作弊嗎？」最好的真實教材。

## 步驟 3｜風格 1 張 `style-natural.jpg`（框衣服＋背景＋配件）
```
清爽自然風格，白色亞麻襯衫，木質細框眼鏡，午後窗邊柔和光線背景
```

## 步驟 4｜被美化版 `beautified.jpg`（刻意示範，框整張臉）
```
美顏濾鏡效果，臉型變小變尖，眼睛放大，皮膚光滑無毛孔，鼻樑更高挺
```
這張要「明顯但不誇張」：學生要能找出 3 個以上差異。

## 輸出
- 直式 3:4，下載 JPG，寬約 1200px
- 依上表檔名放進 `images/`
